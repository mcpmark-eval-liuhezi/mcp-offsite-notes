# MCP Tokyo Research Notes

Briefing notes for the Tokyo team offsite. All entries are drawn from recent web and news searches; every entry cites the source URL it came from.

## MCP in the news

- **Radware introduces MCP server protection** — Markets Insider, Oct 14 2026 (about 3 weeks ago). Radware (NASDAQ: RDWR) introduced MCP server protection to help secure the integration layer of agentic AI. Source: https://markets.businessinsider.com/news/stocks/radware-introduces-model-context-protocol-mcp-server-protection-to-help-secure-the-integration-layer-of-agentic-ai-1036624834
- **Cloudflare's own MCP servers** — Cloudflare Agents docs (about 5 days ago). An MCP server exposing every endpoint as a native tool would consume over 1 million tokens, whereas an efficient approach uses approximately 1,000 tokens regardless of endpoint count. Source: https://developers.cloudflare.com/agents/model-context-protocol/cloudflare/servers-for-cloudflare/
- **Secure your AI agents: free MCP security course** — FreeCodeCamp (about 3 days ago). MCP gives AI agents hands to take real-world actions, introducing a new attack surface. Source: https://freecodecamp.org/news/secure-your-ai-agents-free-model-context-protocol-mcp-security-course
- **What is MCP? The Model Context Protocol, explained** — DEV Community (about 3 days ago). On its own, a language model can only write text; it can't look up today's orders or search your wiki. Source: https://dev.to/bytepenny/what-is-mcp-the-model-context-protocol-explained-35ld
- **Model Context Protocol: the JSON-RPC spec standardizing how AI apps talk to data** — Starlog (about 2 days ago). MCP saves maintaining a nest of custom adapters; caveats: no auth story yet, and the request/response model can't stream. Source: https://starlog.is/articles/ai-agents/modelcontextprotocol-modelcontextprotocol
- **MCP 2026-07-28 spec: stateless core, coming to Claude** — Anthropic Claude blog. The fifth spec release of MCP, 2026-07-28, moves MCP to a stateless core to reduce complexity. Source: https://claude.com/blog/bringing-mcp-2026-07-28-to-claude
- **Donating MCP to the Agentic AI Foundation** — Anthropic news. Anthropic is donating MCP to the Linux Foundation's new Agentic AI Foundation, co-founded with Block and OpenAI, with support from Google, Microsoft, AWS, Cloudflare and Bloomberg. Source: https://www.anthropic.com/news/donating-the-model-context-protocol-and-establishing-of-the-agentic-ai-foundation
- **MCP joins the Agentic AI Foundation** — Model Context Protocol Blog, Dec 9 2025. MCP becomes a founding project of the newly created Agentic AI Foundation (AAIF), a directed fund under the Linux Foundation. Source: https://blog.modelcontextprotocol.io/posts/2025-12-09-mcp-joins-agentic-ai-foundation/
- **Model Context Protocol** — Wikipedia. Open standard introduced by Anthropic in November 2024; adopted by OpenAI and Google DeepMind; created by David Soria Parra and Justin Sphtar-Summers. Source: https://en.wikipedia.org/wiki/Model_Context_Protocol
- **Freshservice MCP integration** — Freshservice Support docs (about 1 week ago). The Freshworks MCP server enables AI tools like Cursor and Claude to securely connect and interact with Freshservice. Source: https://support.freshservice.com/support/solutions/articles/50000012678-model-context-protocol-mcp-integration-in-freshservice
