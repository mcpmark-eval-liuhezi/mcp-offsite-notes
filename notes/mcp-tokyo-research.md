## MCP in the news

- **MCP just got its biggest update ever — here's what changes for AI agents** (VentureBeat) — The 2026-07-28 specification, under the Agentic AI Foundation (AAIF), a directed fund under the Linux Foundation, finalizes the transition to a fully stateless architecture, hardens authentication against a known class of attacks, establishes a formal 12-month deprecation policy, and graduates interactive server-rendered interfaces (MCP Apps) and long-running asynchronous tasks (Tasks) into official protocol extensions. https://venturebeat.com/orchestration/mcp-just-got-its-biggest-update-ever-heres-what-changes-for-ai-agents
- **The 2026-07-28 Specification** (Model Context Protocol Blog) — Stateless protocol core, Multi Round-Trip Requests, header-based routing, cacheable list results, authorization hardening, formal extensions framework, and updated Tier 1 SDKs; since the last November release MCP saw close to half-a-billion downloads a month, with TypeScript and Python SDKs crossing the 1 billion total downloads threshold. https://blog.modelcontextprotocol.io/posts/2026-07-28/
- **The next generation of MCP** (Cloudflare Blog) — The 2026-07-28 specification was released with updated TypeScript, Python, Go, and C# SDKs; MCP is now a fully stateless protocol, with the specification, interaction model, and SDKs rewritten to leverage it. https://blog.cloudflare.com/mcp-v2/
- **The 2026-07-28 MCP Specification Release Candidate** (Model Context Protocol Blog) — A stateless protocol core, the Extensions framework, Tasks, MCP Apps (SEP-1865), authorization hardening, and a formal deprecation policy; breaking changes include moving protocol version/client info into _meta on every request and removing the Mcp-Session-Id header (SEP-2567). https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/
- **mcp gem 1.2.0** (Model Context Protocol Blog) — Full support for the 2026-07-28 revision; today we're excited to publish an updated roadmap for the MCP covering the next specification release and beyond. https://blog.modelcontextprotocol.io/
- **Radware Introduces Model Context Protocol (MCP) Server Protection** (Business Insider Markets) — Radware (NASDAQ: RDWR) introduced MCP server protection to help secure the integration layer of agentic AI. https://markets.businessinsider.com/news/stocks/radware-introduces-model-context-protocol-mcp-server-protection-to-help-secure-the-integration-layer-of-agentic-ai-1036624834
- **Model Context Protocol: The JSON-RPC Spec Trying to Standardize How AI Apps Talk to Data** (Starlog) — Analysis of the protocol's value in scaling with sources; useful if betting on cross-vendor protocol adoption, with caveats about production-grade security and high-throughput streaming. https://starlog.is/articles/ai-agents/modelcontextprotocol-modelcontextprotocol
- **Secure Your AI Agents – Free Model Context Protocol (MCP) Security Course** (FreeCodeCamp) — Course on MCP security given agents' expanded attack surface when connected to tools, databases, and APIs. https://freecodecamp.org/news/secure-your-ai-agents-free-model-context-protocol-mcp-security-course
- **What is MCP? The Model Context Protocol, explained** (DEV Community / BytePenny) — Beginner explanation of what MCP is and how it connects language models to external tools, databases, and APIs. https://dev.to/bytepenny/what-is-mcp-the-model-context-protocol-explained-35ld
- **Model Context Protocol (MCP) Explained for Lawyers and Legal Teams** (LegalDesire) — How MCP links AI to legal tools, which vendors support it, and the security risks and ABA/SRA duties involved. https://legaldesire.com/model-context-protocol
