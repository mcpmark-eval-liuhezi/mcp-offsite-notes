## MCP in the news

Recent headlines on the Model Context Protocol — who is reporting them, with links.

- **OpenAI adopts Anthropic's standard for connecting AI models to data** — TechCrunch (Kyle Wiggers), March 26, 2025. OpenAI said it will add MCP support across its products, including the ChatGPT desktop app and the Responses API, after Microsoft and Google DeepMind had already adopted it; Anthropic's chief product officer Mike Krieger called the standard "a thriving open standard with thousands of integrations and growing". [Source](https://techcrunch.com/2025/03/26/openai-adopts-rival-anthropics-standard-for-connecting-ai-models-to-data/)

- **MCP donated to the Linux Foundation's Agentic AI Foundation** — Wikipedia, "Model Context Protocol" (updated as of mid-2026). In December 2025 Anthropic donated MCP to the Agentic AI Foundation, a Linux Foundation directed fund co-founded by Anthropic, Block and OpenAI. [Source](https://en.wikipedia.org/wiki/Model_Context_Protocol)

- **Security concerns are sharpening around MCP** — Ars Technica (October 2026), "MCP for agent-to-agent comms may be the riskiest protocol you've never heard of". Independent researcher Syed Anas Mohiuddin tested AI agents from Google, JP Morgan Chase, Weviate, Rapid7, the French government's interministerial digital directorate and the US federal government, finding vulnerabilities across the board. Google's MCP database toolbox (googleapis/mcp-toolbox) had an issue rated 8 CVSS stemming from a missing CheckRedirect policy; other organisations also disclosed agent-to-agent vulnerabilities in the same window. [Source](https://arstechnica.com/security/2026/10/vulnerability-in-agents-from-google-and-others-exposes-structural-flaw-in-mcp/)

- **Zero-day risk in AI agents, MCP servers and skills** — Safeguard Blog (October 2026). CVE-2025-49596 in MCP Inspector allowed remote code execution in versions below 0.14.1 because the Inspector client and proxy did not authenticate each other; a CISA KEV entry for CVE-2026-59822 covers an exploited MCP transport endpoint. Anthropic states it does not security-audit or manage MCP servers, and OpenAI says its remote servers "have not been verified by it". [Source](https://safeguard.sh/resources/blog/zero-day-risk-in-ai-agents-mcp-servers-and-skills)

- **mcp-remote has a critical OS command injection vulnerability (CVE-2025-6514)** — DailyCVE (October 2026). The flaw comes from improper input sanitisation when processing server responses during connection handshakes, so the server's `authorization_endpoint` parameter becomes an injection vector. [Source](https://dailycve.com/mcp-remote-os-command-injection-cve-2025-6514-critical-dc-oct2026-3131/)

- **Critical mcp-remote RCE in the wild** — The Hacker News (Lakshmanan Ravie), July 10, 2025, covered via Wikipedia. The advisory reported on a critical remote code execution vulnerability in mcp-remote affecting 437,000+ downloads. [Source](https://www.thehackernews.com/)

- **Nearly half of software companies now run MCP in production** — GlobeNewswire (Radware), October 14, 2026, citing Stacklok's "State of Model Context Protocol in Software 2026" survey: nearly half of surveyed software companies reported using MCP in production, with 19% reporting broad production. Wikipedia (mid-2026 figures) puts MCP servers in production in the thousands and SDK downloads at 97 million+ per month. [Source](https://www.globenewswire.com/news-release/2026/10/14/3380514/8980/en/radware-introduces-model-context-protocol-mcp-server-protection-to-help-secure-the-integration-layer-of-agentic-ai.html)

- **MCP is becoming the universal language for enterprise AI agents** — QUE.com (October 2026). Over 150 organisations supported the standard by April 2026, with a technical steering committee including AWS, Cisco, Google, IBM, Microsoft, Salesforce, SAP, ServiceNow, Cloudflare and Bloomberg. Governance: Linux Foundation Agentic AI Foundation with co-sponsorship from Block, OpenAI, Google, Microsoft, AWS, Cloudflare and Bloomberg. [Source](https://que.com/model-context-protocol-becomes-universal-language-for-enterprise-ai-agents/)

- **U.S. NSA flags MCP as a security risk** — Wikipedia (updated mid-2026): in its May 2026 report the U.S. National Security Agency stated that MCP's "rapid proliferation has outpaced the development of its security model". [Source](https://en.wikipedia.org/wiki/Model_Context_Protocol)
