# MCP Tokyo Offsite — Research Notes

## MCP in the news

Notable recent coverage of the Model Context Protocol (MCP).

- **Figma adds 20 MCP partners as co-founder Dylan Field calls the protocol imperfect** (TechCrunch, Oct 20, 2026) — Figma announced 20 new MCP partners at its first Config conference in India, including Amp, ClickUp, Dia, Junie by JetBrains, Linear, Meta Muse, Mistral, Notion, OpenCode and Sarvam Agents, alongside an updated MCP server. Field described MCP as "not a perfect protocol" with "tons of room for improvement." [Source](https://techcrunch.com/2026/10/20/figma-co-founder-dylan-field-thinks-mcp-is-not-a-perfect-protocol/)
- **Figma, 20 MCP partners** (CryptoBriefing, Oct 20, 2026) — corroborating coverage of the same Config conference announcement and the partner list. [Source](https://cryptobriefing.com/figma-model-context-protocol-20-partners/)
- **While Amazon blocks AI agents, Walmart rolls out the welcome mat** (TechCrunch, Oct 21, 2026) — Walmart's new MCP server, Agent Gateway, lets approved AI agents (including ChatGPT, Gemini and Meta's Muse) search Walmart's online inventory — across Walmart and Sam's Club — and make purchases on behalf of users, with Agent Profiles, spending limits and per-transaction confirmation controls. TechCrunch frames it as the opposite of Amazon's agent restrictions. [Source](https://techcrunch.com/2026/10/21/while-amazon-blocks-ai-agents-walmart-rolls-out-the-welcome-mat/)
- **Notified opens MCP Beta Program for PR and IR Data and Services** (GlobeNewswire, Oct 21, 2026) — new MCP server connecting Content OS™ and IR Hub™ to leading AI agents and client-built systems. [Source](https://globenewswire.com/news-release/2026/10/21/3385795/0/en/notified-opens-model-context-protocol-mcp-beta-program-for-pr-and-ir-data-and-services.html)
- **Financial Cents launches MCP server** (PRNewswire, Oct 20, 2026) — MCP server lets accounting, bookkeeping and tax firms ask questions and take action on their data from Claude, ChatGPT, Gemini and other tools, scoped to one account, authorized by the firm and revocable anytime. [Source](https://www.prnewswire.com/news-releases/financial-cents-launches-mcp-server-to-put-firm-data-to-work-inside-everyday-ai-assistants-302910604.html)
- **Gusto unveils redesigned Gusto Pro, new multi-client MCP** (PRNewswire, Oct 7, 2026) — Gusto launched multi-client MCP bringing Gusto's business context directly into the AI tools accountants already work in, across every client they manage. [Source](https://www.prnewswire.com/news-releases/gusto-unveils-redesigned-gusto-pro-new-multi-client-model-context-protocol-and-expanded-partner-program-for-accountants-302901507.html)
- **Radware introduces MCP server protection** (Business Insider Markets, Oct 14, 2026) — AI and application security vendor Radware (NASDAQ: RDWR) launches MCP server protection to help secure the integration layer of agentic AI. [Source](https://markets.businessinsider.com/news/stocks/radware-introduces-model-context-protocol-mcp-server-protection-to-help-secure-the-integration-layer-of-agentic-ai-1036624834)
- **OpenCode flaw: malicious MCP servers can execute code during sign-in** (The Hacker News, Oct 22, 2026) — a flaw in the OpenCode AI coding agent allowed a malicious or hijacked MCP server to run code on a developer's Windows or WSL machine when the developer signed in. [Source](https://thehackernews.com/2026/10/opencode-flaw-lets-malicious-mcp.html)
- **Cloudflare's own MCP servers** (Cloudflare Agents docs, Oct 22, 2026) — managed remote MCP servers to read configurations, manage services and automate actions across a Cloudflare account. [Source](https://developers.cloudflare.com/agents/model-context-protocol/cloudflare/servers-for-cloudflare/)

Context from the MCP project's own channels: Anthropic introduced MCP as an open standard in November 2024 ([Anthropic](https://www.anthropic.com/news/model-context-protocol)); later donated MCP to the Agentic AI Foundation, a Linux Foundation directed fund co-founded with Block and OpenAI ([Anthropic](https://www.anthropic.com/news/donating-the-model-context-protocol-and-establishing-of-the-agentic-ai-foundation)); the official MCP blog logged the next specification release (2026-07-28) and Version 1.0.0 of the official Ruby SDK ([blog.modelcontextprotocol.io](https://blog.modelcontextprotocol.io/)); Wikipedia notes MCP was adopted by major AI providers including OpenAI and Google DeepMind ([Wikipedia](https://en.wikipedia.org/wiki/Model_Context_Protocol)).

## Shibuya work spots

Places in Shibuya that could host a group of ~6 for an afternoon (coffee or co-working).

- **SARUTAHIKO COFFEE, ATRE Ebisu West Side Store** — Tripadvisor 4.3/5 (32 reviews; ranked #358 of 5,497 restaurants in Shibuya); Tabelog lists 321 reviews. On the 1F of Atre Ebisu West Building, directly connected to Ebisu Station (behind Shake Shack). Hours: daily 08:00–22:00. Phone: +81 3-5422-6970. [Source](https://brand.sarutahiko.jp/shop/atreebisuw) · [Tripadvisor](https://www.tripadvisor.com/Restaurant_Review-g1066456-d10391600-Reviews-Sarutahiko_Coffee_Atre_Ebisu-Shibuya_Tokyo_Tokyo_Prefecture_Kanto.html)

[Source](https://brand.sarutahiko.jp/shop/ebisu) · [Tripadvisor](https://www.tripadvisor.com/Restaurant_Review-g14131018-d3787365-Reviews-Sarutahiko_Coffee-Ebisu_Shibuya_Tokyo_Tokyo_Prefecture_Kanto.html)

Cheaper chain option; less well-rated than the Sarutahiko locations. [Source](https://doutor.co.jp/dcs) · [Tripadvisor](https://www.tripadvisor.com/Restaurant_Review-g1066456-d3827890-Reviews-Doutor_Coffee_Shop_Shibuya_Center_gai-Shibuya_Tokyo_Tokyo_Prefecture_Kanto.html)

[Source](https://lulltechbeach.jp/lp/)
- **Neutrino Coworking Space** — 12-10 Sakuragaokacho, Shibuya, Tokyo 150-0031 (blockchain-themed coworking space; Foursquare lists 39 visitors). Opening hours not listed in the source. [Source](https://office.sumitomo-rd.co.jp/building/detail/shibuya/infoss_annex) · [Foursquare](https://foursquare.com/v/neutrino/5b3304292b274a002c0049d5)

- **WeWork Shibuya Scramble Square** — Tripadvisor 4.2/5 (112 reviews). Hours: Mon–Thu 08:30–20:00 (weekend hours not listed). [Source](https://wework.co.jp/location/tokyo/shibuya-aoyama-area/shibuya-scramble-square)

**Verdict:** for a budget, quick afternoon, the two Sarutahiko cafés are the strongest rated (4.3 and 4.1); for a dedicated work block with power and rooms, LULL TECH BEACH is the best candidate but see review comment below.
